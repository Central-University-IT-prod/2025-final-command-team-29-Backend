# T-Loyalty (Crazy Pappers)

---

T-Loyalty — это единая платформа лояльности в ~~экосистеме Т-Банка~~ (ну почти), объединяющая миллионы клиентов и предпринимателей.

Сервис позволяет малому бизнесу легко создавать и управлять программами лояльности без сложной интеграции и дополнительных приложений. Предприниматели получают удобный личный кабинет для настройки бонусных систем, просмотра аналитики и понимания своей аудитории.

Клиенты могут пользоваться программами лояльности без необходимости запоминать коды, регистрироваться в отдельных приложениях или называть номера телефонов. Все бонусы и скидки автоматически учитываются при оплате через Т-Банк, обеспечивая удобство и бесшовный пользовательский опыт

## Реализация:

**Backend** - Backend представляет собой **REST API**, реализованный на **Go** с использованием следующих технологий:

- **Echo** — веб-фреймворк для обработки HTTP-запросов,
- **GORM** — ORM для работы с базой данных,
- **Zap** — логирование.

В качестве базы данных используется **PostgreSQL**, а для хранения изображений — **MinIO** (S3-совместимое объектное хранилище).

- **Архитектура:**
  Проект построен на чистой архитектуре и реализован в виде монолита.
  **Монолитная архитектура выбрана по следующим причинам:** - над проектом работает небольшая команда, - текущий функционал не содержит сложной логики, - проект находится на этапе MVP, где важны скорость разработки и простота развертывания.

**Дополнительная информация о архитектуре бэкенда:**

- Разделение по слоям:
  - Handlers (Transport) — слой обработки HTTP-запросов,
  - UseCases (Business Logic) — бизнес-логика,
  - Repository (Data Access) — взаимодействие с базой данных.
- Unit-тесты и интеграционные тесты:
  - Unit-тестами покрыты некоторые функции в коде
  - Тестирования API (+ e2e) реализовано через Postman
- DevOps, CI/CD:
  - Автоматизированные сборки и деплой через Gitlab CI
  - Пайплайны
  - Окружения: Dev/Prod(master)

## Тестирование:

### Из мобильного приложения:

Через мобильное приложение можно применять акции (от имени авторизированного пользователя), отслеживать акции.
От имени партнера можо сканирровать коды, применять акции и получать статистику, создавать и удалять акции.
Все перечисленное выше происходит через интерфейс приложения.
